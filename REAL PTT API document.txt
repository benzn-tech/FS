1?Description
The REAL PTT management platform API uses the session to save the login status. When calling the api, you need to carry the cookie, so if you use the ajax method, please add the following parameters:
// ajax
xhrFields: { withCredentials: true },
crossDomain: true
// axios
axios.defaults.withCredentials = trueMost browsers work fine when inter-domain requests, but in Safari, because the browser does not allow cookies to be cross-domain access by default, you need to turn off cross-site tracking in the settings.
If you need to call the interface through a secure ssl link, you can change all https://api.realptt.com to https://realptt.com.


2?Login relevant
2.1?Obtain random number
Brief description: 
* Obtain the login random number interface and make the key encrypted by HMAC_SHA1
* The sessionId in the return parameter is the current session ID. If you are accessing from a non browser, such as Java, or the browser has disabled cookie, you need to add "; jsessionid=xxx" (before the "?" symbol) to the address of other interfaces, such as logging in:              https://api.realptt.com/ptt/organization;jsessionid=2A93430B488F143A0455E7944FEAC6B2?method=login&account=test&pwd=117ec9786dd6f5d0e0247bdbf33097c8b9524546&timeZoneOffset=-480
* 
Request URL: 
* GET https://api.realptt.com/ptt/random
Parameter: 
* N/A
